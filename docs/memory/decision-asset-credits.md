Third-party assets (models, textures, sounds) are listed in CREDITS.md and shown in the pause menu "Credits" card. CC-BY assets require attribution, so add the exact required line when importing one.
Why: CC-BY 3.0 legal requirement (first case: Crab by Poly by Google, Poly Pizza).
How to apply: add to CREDITS.md + the CreditsText label in scenes/ui/pause_menu.tscn.
