## Dev tools
- `DevTools` autoload (`scripts/dev_tools.gd`): with user arg `--shot=PATH`, saves a viewport screenshot after 2 s and quits. Inert otherwise.
- `tools/check`, `tools/shot`: shell wrappers (see README). Logs in `.logs/`.

## Beach & environment (`scenes/beach.tscn`, `scripts/beach.gd`, `assets/`)
Everything visible is a node or resource in `scenes/beach.tscn` (editable in the editor): `WorldEnvironment` (`assets/env/beach_env.tres`: custom sky material `assets/materials/sky.tres`, ACES, glow, SSAO, fog + volumetric fog), `Sun` DirectionalLight3D (shadow settings), `Terrain` (MeshInstance3D, `scripts/terrain.gd`), `Water` (PlaneMesh + `assets/materials/water.tres`), `DuneGrass` (MultiMeshInstance3D, `scripts/dune_grass.gd`), `Props` (10 `scenes/props/palm.tscn` + 10 `rock_cluster_a/b/c.tscn` instances, positions set by hand/generator, y from height_at), and `Lighthouse` (`scenes/props/lighthouse.tscn`: Poly Pizza glb scaled x2 ≈ 17 m + warm OmniLight3D lamp; at x=-62, z=2 on a headland with 3 base rock clusters, decor only, no collision), and `Player` (instance of `scenes/player.tscn`). Meshes are baked `.res` in `assets/meshes/` (terrain, palm trunk/frond, rocks, grass blade, dune grass multimesh); materials in `assets/materials/` (sand, water, grass, sky = ShaderMaterial on `assets/shaders/`; leaf, trunk, rock = StandardMaterial3D with vertex colour).
- `Beach` (`scripts/beach.gd`, `@tool`, group `beach`): `_ready` applies the look, connects `GameState.health_changed` and calls `_spawn_gameplay()` (DebrisManager, Shack, HUD, Menu, Cheats, Wildlife; still script-built). Editor: select Beach and move the `health` slider (or edit a look `.tres`) to preview the look live; the runtime-only stuff is skipped in the editor.
- Look = `BeachLook` resource (`scripts/beach_look.gd`, `@tool`): sun elevation/azimuth/colour/energy, sky colours + clouds, fog, ambient, saturation/contrast/glow, water, sand, grass, palm tints. Files in `assets/env/`: `look_polluted.tres` (health 0), `look_restored.tres` (health 1), `look_golden.tres` (golden-hour overlay, weight `smoothstep(0.85, 1, health)`). `set_health(t)`: `look = polluted.mix(restored, t^0.8).mix(golden, sunset)` then `_apply_look()` writes sun, sky material, environment and the sand/water/grass/leaf materials (exported on Beach). `BeachLook.mix(other, t)` lerps every exported float/Color.
- `Terrain` (`scripts/terrain.gd`, `@tool`) owns `shore_z(x)` and `height_at(x, z)` (Beach delegates; safe to call before any `_ready`) and the noise (`get_noise()`). Mesh is baked to `assets/meshes/terrain.res` (1 m grid, x -70..70, z -80..70; sea +Z, dunes -Z, shoreline near z~0, headlands at x ends); inspector button "Bake mesh" regenerates it after editing `height_at`. Trimesh collision (`TerrainBody`) is created at run time. `DuneGrass` has a "Scatter" button (re-bakes `assets/meshes/dune_grass.res`; re-run it after changing the terrain). Palms/rocks are not re-placed automatically.
- Shaders: `sand` (patches, near-camera blotch/mottle detail, stronger wind ripples with darker troughs, wet band, dune tint), `water` (vertical depth colour from depth texture, swell+chop, foam bands, noise normals), `sky` (gradient, sun glow/disc, cartoon clouds), `grass` (sway, backlight).
- API: `set_health(t: float)` (0 = grey, cool, murky, overcast, flat high sun; 1 = vibrant, golden low sun, turquoise water). Starts at health 0 (or the saved health). `height_at(x, z) -> float` gives ground height (use for spawning debris/props). `shore_z(x) -> float` gives the shoreline z at x. Dev: user arg `--health=0.7` overrides the start value.
- Player (`scenes/player.tscn`, `scripts/player.gd`): CharacterBody3D with CollisionShape3D (capsule), `Head` (y 1.6) and `Camera3D` (fov 75) nodes; `beach` = its parent. Instanced in beach.tscn, so it exists before `_spawn_gameplay` runs.
- Perf: ~120 fps (vsync cap) on RTX 3070 Mobile at 1600x900.

## Gameplay (tasks 3-4)
- `GameState` autoload (`scripts/game_state.gd`): `cents` (money, integer cents), `pending` (cents of a bag still being sorted), `bag_capacity` (space units, float, 10), `bag` (Array of {id,value,space}), `cleared_count`, `initial_count`, `health()` = cleared/initial (0..1). Methods `bag_used()`, `bag_value()`, `can_add(space)`, `add_to_bag(id)` (emits `bag_full` and returns false if no room), `add_money(n)`, `take_bag()` (empties the bag, value to `pending`), `pay(n)` (adds money, emits `sold`), `sell_bag()` (take+pay, no animation: tests), `set_initial_count(n)`, `register_clear()` (tide pieces count too, capped at initial). Signals `bag_changed`, `money_changed`, `health_changed(v)`, `bag_full`. Task 5 below.
- `Player` (`scenes/player.tscn` + `scripts/player.gd`, CharacterBody3D, group `player`, instanced in beach.tscn): WASD (physical keys), mouse look, captured mouse (Esc releases, click recaptures), head bob. Stats vars `reach` (2.5), `move_speed` (5.0) for upgrades. Clamped to x +-50, z in [shore-33, shore+1.2]. Every physics frame a ray (mask terrain+debris) sets `target` (debris, bottle or coin within reach, with the HUD label) and calls `set_highlight`; left click -> `_try_pickup()`. Dev args `--pos=x,z,yaw_deg[,pitch_deg]`, `--pitch=DEG`.
- `Catalog` (`scripts/catalog.gd`, preload, no class_name): THE data table. `ITEMS` (id -> name, space, value cents, bin, weight), `BIN_ORDER` (bin ids in emptying order; name/colour/icon are exports on the `Bin` instances in shack.tscn), `COINS` (loose-change values/weights), helpers `random_id`, `random_coin`, `money(c)` ("$12.34"), `price(c)` ("10¢" or "$1.50"), `num(x)` (6.5 / 10); scene lookups `item_scene(id)`, `coin_scene(cents)`, `BOTTLE_SCENE`.
- **Item prefabs** (`scenes/items/`): `<id>.tscn` for the 10 debris types, `coin_5/10/25/100.tscn`, `message_bottle.tscn`, `sand_puff.tscn`. Debris prefab = StaticBody3D (`debris.gd`, exported `id`, layer 2, group `debris`) > `Visual` (VIS_SCALE, sunk by `rest`) > `Model` (`scripts/item_model.gd`, scale = per-item real-size factor, exports `rest`, `can_stand`, colour `variants`/`accents` material lists + the parts they apply to) > `Pose` (lying pose) > MeshInstance3D parts (primitive meshes as sub_resources). Materials are shared `.tres` in `assets/materials/items/` (colour variants e.g. `cap_red.tres`, `outline.tres` highlight, `sparkle.tres`, `puff.tres`; shader `assets/shaders/item_outline.gdshader`). Prefabs were generated once from the old code; now edit them in the editor. `Catalog.VIS_SCALE` is re-applied at runtime to `Visual` (the baked 1.4 is only for editor display).
- `ItemMesh` (`scripts/item_mesh.gd`): `build(id, rng, upright=false) -> Node3D` plain model of one item at real size (meta `rest` = centre height): instances the prefab and keeps only its `Model` (random colour variant; `upright` stands bottles/cans/caps/flip-flops up). Used by the bin icons and the flying copies while sorting; API unchanged.
- `Debris` (`scripts/debris.gd`, StaticBody3D, layer 2, group `debris`): create with `Debris.spawn(id, rng) -> StaticBody3D` (instances `scenes/items/<id>.tscn`, random colour variant, yaw, tilt), then add_child and place. `id` (exported), `value`, `space` (set in `_ready` from `Catalog`); drawn `Catalog.VIS_SCALE` (1.4x, one uniform factor) life size, partly sunk; pick sphere baked in the prefab = max(`MIN_PICK_RADIUS`, size-based). `label_text()` ("Soda can · 10¢"), `set_highlight(on)` (`outline.tres` as `material_overlay`), `pick_up(cam)` (pop up, shrink toward camera, `sand_puff.tscn`, queue_free), `refuse()` (shake), `pop_in()`.
- `LooseChange` (`scripts/loose_change.gd`, StaticBody3D, layer 2, group `coin`): 5¢/10¢/25¢/$1 coin prefabs (`coin_<cents>.tscn`, exported `cents`), create with `LooseChange.spawn(cents, rng)`; twinkling sparkle quad; Player adds the money instantly (`add_money`), tick sound, never in the bag, no health effect. Not saved (10 respawn on load, tide sometimes brings one).
- `DebrisManager` (`scripts/debris_manager.gd`): instances the item prefabs; scatters 340 pieces (weighted by `Catalog`, denser near shore, skips water, min spacing) plus 10 loose coins, then a 90 s Timer calls `tide()`: 7 -> 2 new pieces near the waterline as health rises (40% chance of a coin), total capped at 400. Dev arg `--showcase` lays out one of everything in front of the default start.
- **UI as scenes**: all UI lives in `scenes/ui/*.tscn` (Control nodes laid out in the editor, unique-name `%` nodes) with ONE shared `assets/ui/theme.tres` (StyleBoxFlat panels/bars/buttons + Label/Button/RichText type variations: HudPanel, ShopCard, MenuCard, PaperCard, RowPanel, BuyButton, PaperButton, ...). Scripts hold behaviour only. Add `load()` (not `preload`) of scenes whose scripts touch autoloads, or `tools/check` goes RED.
- `HUD` (`scripts/hud.gd` + `scenes/ui/hud.tscn`, CanvasLayer, group `hud`): rounded panel (`Bag 6.5 / 10` + fill bar that warms toward full, money `$0.00`, health % + bar), crosshair that grows a ring when `set_aiming(true, text)`, with a small label under it (name + value) from the target's `label_text()`, "Bag full!" flash + panel shake, "Click to play" when mouse released.
- `tools/check` now also boots the main scene headless for 30 frames (autoload-aware) and ignores `--check-only`'s false "Identifier not found: <Autoload>" errors.

## Shack & upgrades (task 5)
- `GameState` also owns `levels` (dict id->level), `UPGRADES` table (base cost in CENTS: bag 240, arms 360, grabber 600, sandals 300, rake 720; max 8/6/5/5/4), `cost(id)` = base x 1.6^level, `can_buy`, `buy(id)`, `is_maxed`, `effect_text(id)`, effect getters `reach()`, `move_speed()`, `grab_rate()` (0 = none; 1.5+level per s), `rake_radius()` (0.6 m x level); `bag_capacity` = 10 + 5 x level space. Signals `upgrades_changed`, `sold(amount)`. Dev arg `--coins=CENTS`.
- `Player.apply_upgrades()` (on `upgrades_changed`) sets `reach`/`move_speed`. `_collect(d)` is the single pickup path (click, grabber, rake): rake also takes pieces within its radius of the picked one if they fit. `grab_tick()` (hold LMB, rate from grabber level) vacuums the piece nearest the view centre inside a 15 deg cone within reach; never exceeds capacity.
- `Shack` (`scripts/shack.gd`, Node3D, group `shack`, instanced by beach before the debris manager): hut is `scenes/shack/shack.tscn` (hut, awning, sign, counter, crate, surfboard, `SellSpot`/`ShopSpot` Marker3D, 4 instances of `scenes/shack/bin.tscn`; materials `assets/materials/shack/*.tres`; `scripts/bin.gd` @tool tints a bin from exported `bin_id/bin_color/label_text/icon_id/icon_scale` and builds the icon via ItemMesh at runtime; shack.gd is behaviour only, snaps crate+bins to the ground), hut at x=14, ~21 m behind the shoreline, facing the sea; `occupies(p)` keeps debris off it. Two interact spots (2 m radius each, nearest wins, prompt via `HUD.set_prompt`): the bins right of the hut (local 4.55,2.7) = SELL (`E — Recycle bag (+$X.XX)`, or soft `Bag empty`; never opens the shop); the counter (local 0,2.7) = SHOP (`E — Upgrades` opens the panel; E/Esc close). `_zone()` returns sell/shop/"". Dev args `--open-panel`, `--sort-demo` (sell ~1.55 s after start; combine with `--fill`).
- **Sorting bins**: four box bins (Cans blue, Bottles green, Glass amber, Other orange) (`scenes/shack/bin.tscn`), each with a swinging lid, dark mouth and a plate with an item icon + name. `sell() -> cents`: `GameState.take_bag()`, group items by `Catalog` bin, plan a timeline of timers (`_at`): per bin in `BIN_ORDER` its lid opens (`_lid`), items fly out of the bag position as small `ItemMesh` copies (`_launch`/`_fly`: arc + shrink), land with `Sfx.bloob(step)` (pitch rises along a pentatonic scale, capped; at most ~14 sounds) and a bin squash, lid closes; finally `_finish_sort` calls `GameState.pay` (cash sound via `sold`, coin burst, money counts up). Per-item interval shrinks with item count; above 24 items one flyer stands for several. Whole sequence ~1.3 s, always under 2 s. Runs on timers, so walking away is fine; `_sorting` blocks a second E.
- `UpgradePanel` (`scripts/upgrade_panel.gd` + `scenes/ui/upgrade_panel.tscn`, one `upgrade_row.tscn` instance per upgrade, CanvasLayer 20, instanced by Shack): cream rounded card, one row per upgrade (name, level, current > next effect, Buy $X.XX button disabled if unaffordable/MAX). `open()`/`close()`/`is_open`; frees/recaptures the mouse.
- HUD: money counts up (about 0.6 s) with a scale pop and floating "+$0.25"; `set_prompt(text, hold)` shows the bottom prompt.
- Test: `godot --headless --path . res://tools/tests/t5_test.tscn` prints `T5 PASS`.

## Restoration (task 6)
- `GameState.MILESTONES` (id/at/msg: crabs 25%, gulls 50%, turtle 75%, hatchlings 100%), `reached` list, signal `milestone_reached(id)` emitted once per id from `register_clear()`.
- Beach: `GameState.health_changed` -> `_on_health_changed` tweens `set_health` over 2 s (sine). `set_health` also has a golden-hour `sunset` term (smoothstep 0.85..1: lower sun, orange horizon/fog).
- `Wildlife` (`scenes/wildlife/wildlife.tscn`, root script `scripts/wildlife.gd`, instanced by beach which sets `beach` var; group roots are scene nodes Crabs/Gulls/Turtle/Hatchlings). Each animal is a prefab in `scenes/wildlife/` (`crab`, `gull`, `turtle`, `hatchling`, `nest`.tscn; shared materials `assets/materials/wildlife/*.tres`); the script instances them and drives animation by finding named parts (Wing0-1/WingTip, Head, Flipper0-3; crab: `Body` node). Animals: crabs (5, ping-pong along the waterline; `crab.tscn` instances `assets/models/wildlife/crab.glb`, a single-mesh CC-BY model without animations, scaled 0.00064 and turned 180 deg; waddle bob/tilt on `Body` driven procedurally; credited in CREDITS.md), gulls (4, circling over the sea, glide/flap), turtle (1 at x=3.5, head bob + flippers), hatchlings (8 + sand nest at x=-3, walk to the sea, shrink into surf, loop). Everything animates in `_process` from `_t`; no collision (cannot block the pickup ray). Per-group `_ap` factor scales animals in (1.4 s, back-ease) on `milestone_reached`; on load groups at/below `max(GameState.health(), beach.health)` appear instantly (so `--health=1` shows all).
- HUD `toast(text)`: centre-top cream pill, shown on `milestone_reached`, fades after ~3 s.
- Test: `godot --headless --path . res://tools/tests/t6_test.tscn` prints `T6 PASS`.

## Bottles & save (task 7)
- `Notes` (`scripts/notes.gd`): `SPOTS` (5 fixed [x, depth-behind-shore]) and `TEXTS` (BBCode, `[i]` = photo fragment).
- `Bottle` (`scripts/bottle.gd`, StaticBody3D, layer 2, group `bottle`, not `debris`): prefab `scenes/items/message_bottle.tscn` (glass + paper roll + twinkling stars; instance it, call `setup(note_id)`); spawned by DebrisManager (skips found ones). Player ray also targets `bottle`; click -> `menu.show_note(id)`; no bag space, no health effect.
- `Menu` (`scripts/menu.gd` + `scenes/ui/pause_menu.tscn`, CanvasLayer 30, group `menu`, process ALWAYS, instanced by beach; the paper note is `note_overlay.tscn` + `scripts/note_overlay.gd`, `show_note(id)`; floating `+$` is `float_text.tscn`): states PAUSE (Resume/Notes/Quit), LIST (found notes, "???" for unfound), NOTE (paper card). Pauses the tree while open. Player Esc -> `open_pause()` (no longer just frees the mouse); Esc/E/click close note, Esc steps back, resume recaptures. Dev args `--pause`, `--pause=notes`, `--note=N`, `--found=0,3`.
- Save: `GameState.save_game()/load_game()/to_dict()/from_dict()` -> `user://save.json` (version 2: cents, bag as item ids, levels, cleared, initial, reached, found notes, debris [{id,x,y,z}]); a file with another version is ignored (fresh game). Loaded in GameState `_ready`; `loaded_debris` consumed by DebrisManager (null = scatter fresh). Saves: every 30 s, on sold, on note found, WM_CLOSE_REQUEST, menu Quit. Beach starts at `max(health, GameState.health())`. Dev arg `--fresh`: ignore save and never write (tools/check and tools/shot pass it).
- Test: `godot --headless --path . res://tools/tests/t7_test.tscn` prints `T7 PASS` (uses user://t7_test.json; the corrupt-file case logs a JSON parse error, expected).

## Polish (task 8)
- `Sfx` autoload (`scripts/sfx.gd`): all audio is generated at startup (AudioStreamWAV, no asset files), 8-voice player pool + a separate 6-voice pool for bin bloobs. `pickup(id)` blip (bigger item = lower pitch, called from `Debris.pick_up`), `tick()` tiny coin tick (loose change), `bloob(step)` soft bin landing (-19 dB, pitch capped at +1 octave), `coin()` on `GameState.sold`, `chime()` on `milestone_reached`, low thud on `bag_full`, `step()` faint sand crunch (6 noise-grain variants, random pick + volume/pitch jitter) called by the Player once per head-bob dip while moving, plus a looping 8 s ambient wave bed (low-passed noise, slow swell, -17 dB).
- Tuning (see `tools/tests/tune_sim.tscn`, an estimate not a test; reads `Catalog` weights/space/value): `DebrisManager.INITIAL_COUNT` 340, `MAX_ALIVE` 400, upgrade base costs in cents 240/360/600/300/720 (bag/arms/grabber/sandals/rake, still x1.6 per level), tide unchanged. Average piece 8.9¢ and 0.93 space. Estimate for a reasonable player: first upgrade ~1.1 min, 25% ~2.7 min, 50% ~5.0, 75% ~7.4, 100% ~15 min (13.4 fast aim, 16.8 slow aim); loose change (~$1.4 total) is ignored by the sim. Tests must run with `-- --fresh`.

## Cheats (task 9)
- `Cheats` (`scripts/cheats.gd` + `scenes/ui/cheats.tscn`, CanvasLayer 40, instanced by beach): F1 toggles a plain button panel (mouse freed, not paused; ignored while pause menu or shop is open). +$1/+$10, max upgrades, fill bag (random catalog mix), clear 10%, health 25/50/75/100 (`_set_cleared`: removes real debris via `register_clear` so milestones fire; lowering re-scatters via `DebrisManager.scatter(n)`), spawn tide, reveal notes, fast walk (`Player.speed_mult` x3), Reset (2-click confirm: `GameState.reset()` wipes save + reload scene). Dev args `--cheats`, `--fill`. DebrisManager is in group `debris_manager`.

## Aim target interface
Anything the player can aim at (groups `debris`, `bottle`, `coin`; layer 2) must implement `label_text() -> String`, `set_highlight(on)`, `pick_up(cam)`, `refuse()` (Debris, Loose change, Bottle all do). `Player._update_target` calls them blindly. Guarded by `tools/tests/t11_test.tscn` (aims at one of each kind).

## Gallery
`scenes/gallery.tscn` (`scripts/gallery.gd`): open in the editor and press F6. Everything is placed in the scene (item prefab instances under `Items`, flat Label3D labels, ruler, 1.75 m figure, beach-like sky/sun/ground), so the editor shows it without running; the script only spins the `Items` children, randomizes colour variants (seed 7) and drives the camera (A/D, arrows, drag, wheel, W/S; dev `--focus=X`). Items are drawn VIS_SCALE x life size; the figure is life size.
